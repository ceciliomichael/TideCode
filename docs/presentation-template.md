## Slide 2 — What EchoSphere Is + Problem Solved
- EchoSphere is a desktop AI workspace built with Electron, Vite, and React.
- It combines chat, workspace awareness, file inspection, source control, terminal support, and settings in one place.
- The main problem it solves is context switching between chat, files, terminal, and git tools.
- It keeps project context, task history, and AI interaction in one workspace.

## Slide 3 — Agent Architecture
- **Plan mode**: helps with understanding, discovery, and task breakdown.
- **Agent mode**: supports more active work and tool use.
- Core parts of the app:
  - Chat workspace
  - Project and file awareness
  - Source control support
  - Terminal support
  - Settings and model control
  - Conversation history / workspace memory
- Optional visual: add an architecture diagram showing how chat, workspace state, tools, and models connect.

## Slide 4 — Demo
- Show the app opening into the main workspace.

## Slide 5 — Key Challenges + Closing
- Keeping the AI grounded in the current project context.
- Balancing helpful automation with user control.
- Managing conversations, workspace state, and settings consistently.
- Supporting multiple tools and views without making the interface feel crowded.
- Closing message: EchoSphere is a practical AI workspace that reduces context switching and supports both planning and execution.
