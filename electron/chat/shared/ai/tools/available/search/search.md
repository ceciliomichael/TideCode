# tools.available.search.search

Find authorized tools by capability, keyword, exact name, or MCP server namespace. Searching an exact server namespace lists its authorized tools, ten per page by default. Use `namespace: "github", query: "issues"` to search only GitHub tools, or omit `namespace` to search all authorized tools. Optional `query` and `namespace` are strings; `limit` is an integer from 1 to 10 and `offset` is a nonnegative integer. Results are ranked by matching name tokens, namespace, and tool descriptions. Results contain callable names, brief descriptions and continuation instructions, never signatures or parameter schemas. Prefer `tools.available.list` for browsing namespaces and their tools.
