# tools.available.search.search

Find connected MCP tools by capability, name, description, or server namespace. With no namespace, search only connected MCP tools. To search native tools, explicitly supply one of the authorized native namespace names in the current hidden chat-mode context; unfiltered searches do not return native tools. Results are ranked by matching name, description, and namespace. `limit` is from 1 to 10 and `offset` is a nonnegative integer. Each result includes a callable tool name and short description, not an argument schema. Use `tools.available.get({ name })` to retrieve the exact contract before execution.
