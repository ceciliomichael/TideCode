# tools.available.list

List currently authorized native namespaces and connected MCP server namespaces, ten entries per page. The root view shows only namespaces with registered tools. Pass a listed namespace to see its tools and their exact callable names. Namespace names are discovery categories, not API prefixes: `native_files` contains `tools.list`, not `tools.native_files.list`. MCP descriptions come from server metadata when available. Tool entries include short descriptions but not signatures. `page` is 1-based and paginated independently per view. Retrieve full contracts using `tools.available.get({ name })`.
