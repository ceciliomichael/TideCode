# tools.available.list

List connected MCP server namespaces with their descriptions, ten entries per page. The root view omits native namespaces because the current hidden chat-mode context supplies the native catalog. To list tools within an authorized native namespace, explicitly pass its exact namespace name from that context. To inspect a connected MCP server, specify its listed namespace. MCP server descriptions come from server metadata when available, otherwise a neutral fallback. Tool entries include short descriptions but not signatures. `page` is 1-based and paginated independently per view. Retrieve the full API contract using `tools.available.get({ name })`. Obsolete combined namespace aliases are unsupported.
