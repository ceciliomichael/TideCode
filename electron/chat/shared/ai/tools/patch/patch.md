# tools.patch

Apply an atomic raw Codex patch. Read exact source before constructing a patch. Use complete source lines in contextual hunks, order hunks top-to-bottom, and include a distinctive `@@` context or appropriate line position when similar blocks repeat. The matcher normalizes line endings and supports contextual whitespace differences, but do not rely on fuzzy matching to select ambiguous blocks. Updates preserve source line endings and UTF-8 BOM. All hunks are staged before writing and recoverable failures roll back committed files. If a hunk fails, reread the reported source lines and reconstruct the failed hunk; do not repeatedly submit the same invalid patch. Put literal multiline patch text in outer `exec.payloads` and pass its payload reference as `patch`. Preserve source backticks and interpolation expressions as data; do not wrap the raw patch in a JavaScript template literal or String.raw. In Plan Mode, edits are restricted to the active plan.
