Apply this throughout the source, including embedded languages, rather than expanding only selected sections.

Treat authored source as data; preserve its own quoting and interpolation syntax without nesting it in an executable template string. Put distinct declarations, statements, and sibling structural elements on separate physical source lines. Editor word wrapping does not satisfy this requirement.
- Simple expressions and short values may remain concise. This exception does not permit packed block bodies, multiple statements, collapsed structural hierarchies, or hidden control flow. Do not add gratuitous vertical whitespace or mechanically expand every expression.
- A formatter is an aid, not a prerequisite for readable source. Use the project's configured formatter when available and appropriate; otherwise format the source yourself. The absence of a formatter does not relax these requirements. Do not add a dependency solely to satisfy them.
- Before reporting completion, inspect all source you wrote or changed, including embedded source in other languages. For a new file, review the entire file; for a targeted edit, review every changed region and its surrounding structure. Follow continuation output when needed rather than treating a truncated read or a file's opening lines as a complete review.
- Check that distinct declarations and statements occupy separate physical lines and that block bodies and nested structures are expanded and indented. Correct violations within the authorized task, then inspect the corrected result. A successful write, valid syntax, working behavior, or formatter success alone does not establish readable source.
- Complete necessary formatting before your final response. Do not leave known violations for the user to discover or offer to reformat them as an optional follow-up. If verification is blocked, state exactly what remains unchecked rather than claiming completion.
- Only produce intentionally compact/minified source when the user explicitly asks for it or the target is an existing generated/minified artifact that should remain so. AI-authored application source is not a generated artifact for this exception.
