# Sidebar Project Selector

Updated 2026-10-21.

- Keep Chats in the history filter, not in the project dropdown. The project dropdown has no selection checkmarks.
- Project rows show the project title above its path or description, and row highlighting follows hover.
- The ellipsis action appears with the project row on desktop hover. Its icon has its own scale and color hover feedback plus a "Project actions" tooltip to the right of the icon and above the dropdown menus, without a button background. Hovering the icon also highlights its project row without selecting it. The Rename/remove actions menu opens at the icon's click position, like the Explorer context menu, and stays inside the viewport; the tooltip closes while the menu is open.
- Choosing a project immediately filters history to it and keeps that filter selected when its new conversation is created.
