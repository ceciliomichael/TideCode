# Release via PR

Goal: release the current repository state. Steps: (1) inspect git status/branch and .github/workflows/release_instructions.md, (2) ensure the intended changes are committed on a non-main branch, create a PR, and merge it to main, (3) follow the release instructions exactly from main, (4) verify the release/tag/workflow outcome. Scope: no unrelated code changes.
